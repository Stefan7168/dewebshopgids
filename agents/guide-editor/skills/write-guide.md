# Write the weekly gids

Audience: Dutch Home & Living buyers, 35 to 60, who want unique and trustworthy shops. Informal "je". Plain, warm, factual. About 150 to 300 words, never more than 350.

Shape:
- Title: under 60 characters, names the week's theme from the data, for example "Drie nieuwe makers en een stijger".
- Intro: one or two sentences on what this week's selection is.
- Body: one block per shop, in the order of the inputs:

```
## [Shop name](/webshop/shop-slug)

Two or three sentences using only the facts: category, score ("echtheidsscore 82 van 100"), online since, product count text, keurmerk text, city. For reason "nieuw": new in the gids. For "score_gestegen": the score rose by the given change. For "veel_bekeken": say it is a shop many readers looked at, without numbers.
```

Copy numbers exactly as given. Write years as given ("online sinds 2014"). Use the product text as given ("ongeveer 120 producten"). Do not round, add or compare numbers.
